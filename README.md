# Simply Sorted by Gail

A beautifully designed, premium static website tailored for professional home organizing. The site features a warm, elegant aesthetic with taupe, creamy off-white, and dark brown tones, perfectly complementing the custom "Simply Sorted" brand logo.

## Features
- **Responsive Navigation:** A fixed, glassmorphism-styled navigation bar optimized for both desktop and mobile viewing contexts.
- **Dynamic Hero Slideshow:** A fully native, vanilla JavaScript carousel displaying high-end organizing spaces (pantries, walk-in closets, home offices) with soft fade and zoom animations.
- **Premium Aesthetic:** Built using modern typography (`Outfit` from Google Fonts), soft component blurs, and elegant, soothing color transitions.
- **Quick Contact Actions:** Frictionless user touchpoints featuring direct phone line linking and pre-formatted email templates.
- **Lightweight Architecture:** Built without bulky node modules or heavy frameworks, ensuring blazing fast load speeds directly in the browser.

## File Structure
- `index.html`: The core HTML structure forming the main landing page.
- `style.css`: The styling rules governing the responsive layout, elegant colors, animations, and typography.
- `main.js`: The underlying logic powering the sliding hero imagery.
- `assets/`: Directory containing the aesthetic site photography and the official `logo.png`.

## Local Development & Viewing
Because this is a completely static, ready-to-go site, no complex build dependencies are required! 
1. **The easiest way:** Simply double-click the `index.html` file on your computer to open it in your default web browser (Chrome, Safari, etc.).
2. **The developer way:** Open the project in your terminal or a code editor like PyCharm and launch a fast local server by running `python3 -m http.server 3000` or `npx serve .`.

## Deployment
This project is fully designed and optimized to be seamlessly tracked and deployed via **GitHub Pages**. Simply push this codebase to your `main` branch, navigate to your repository's settings, and enable Pages routing exclusively pointing to the root directory `/`.
